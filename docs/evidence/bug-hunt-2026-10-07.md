## Conclusion

Second round, after the first (2026-10-05) found nothing novel either. This run specifically
targeted two angles a manual search of github.com/MystenLabs/MemWal/issues turned up no coverage
for: whether namespace matching is really byte-exact, not just documented as such — case folding
and Unicode normalization (NFC vs NFD) are both plausible places for a relayer to silently fold
two "different" namespaces into one, which would be a real memory-isolation bug.

Both held: writing to a namespace and recalling from a case-different or Unicode-equivalent
variant found nothing, confirming the relayer does exact byte matching as documented. This is a
genuine result — independent confirmation that namespace isolation, which this project's security
depends on (one bot account serves many Telegram groups), is sound — just not a *bug*, so nothing
was opened.

No new GitHub issue opened in this round either. Combined with the first round: 9 probes across
two days, 0 novel findings. The MemWal tracker appears to already be worked heavily (likely by
other participants doing the same Bug Bounty track), which makes finding an unreported issue
through generic exploratory probing increasingly unlikely without a much more unusual angle or
more time than is left before the submission deadline.
